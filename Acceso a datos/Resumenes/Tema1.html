1. Definición y tipos de ficheros

Fichero: sucesión de bits que finalmente son almacenados en un determinado dispositivo. Está compuesto por nombre y extensión (indica la tipología del archivo).

Tipos de fichero:

• De texto (ASCII): en su interior encontraremos líneas de texto organizadas en código ASCII. Algunos de los ejemplos son: archivos de aplicaciones de ofimática, archivos de programas de los distintos lenguajes de programación, ficheros de imágenes, de video, etc.

• Binarios: aquellos ficheros cuya información está representada en código binario. Para poder leer dichos ficheros, antes debemos saber cómo fueron escritos para escoger la misma lógica en su lectura. Algunos son .bin, .dat… entre otros.

/**
 * Mueve un fichero a un directorio destino usando renameTo.
 * Devuelve true si se movió, false si falló.
 */

public static boolean moverFichero(String rutaOrigen, String rutaDirectorioDestino) {
    File origen = new File(rutaOrigen);
    File destinoDir = new File(rutaDirectorioDestino);
    if (!destinoDir.exists()) destinoDir.mkdirs();
    File destino = new File(destinoDir, origen.getName());
    return origen.renameTo(destino);
}

2.1 Diferencia entre secuencial y directa o aleatoria

Los ficheros de acceso secuencial deberán ser recorridos byte a byte o carácter a carácter con el tiempo, procesado de la información, y uso de recursos que esto conllevaría, mientras que, en los ficheros de acceso aleatorio o directo, se establecerá un puntero en bytes, el cual indicará la posición exacta donde vamos a realizar la lectura y/o escritura, y al que se podrá acceder directamente.

2.2. Acceso secuencial con bytes

Nos facilitan la lectura o escritura de un fichero como un “stream” de bytes. Para ello nos apoyaremos en la clase FileInputStream (lectura entrada de datos) y FileOutputStream (escritura salida de datos)". read() devuelve un int con el siguiente byte, o -1 al llegar al final del fichero.

2.2.1 FileInputStream

Esta clase nos facilitará la lectura de los ficheros binarios.

Java
FileInputStream fis = new FileInputStream("datos.bin");
int b;
while ((b = fis.read()) != -1) {   // -1 = fin de fichero
    System.out.println(b);
}
fis.close();

2.2.1 FileOutputStream

Esta clase nos facilitará la escritura de ficheros binarios.

Java
FileOutputStream fos = new FileOutputStream("salida.bin");
fos.write(65);                   // byte 65 ('A')
fos.write("Hola".getBytes());    // array de bytes
fos.close();

2.3. Acceso secuencial con caracteres

FileReader y FileWriter trabajan directamente con caracteres. La lógica es parecida a la de los streams de bytes, pero read() devuelve un int que hay que castear a (char) para mostrarlo.

FileWriter crea el fichero si no existe y lo sobrescribe si ya existe.

2.3.1 FileReader

Esta clase nos facilitará la lectura de los ficheros de caracteres.

Java
FileReader fr = new FileReader("pruebas2.txt");
int c;
while ((c = fr.read()) != -1) {
    System.out.print((char) c);    // casting a char
}
fr.close();

2.3.2 FileWriter

Esta clase nos facilitará la escritura de ficheros de caracteres.

Java
FileWriter fw = new FileWriter("pruebas2.txt");   // sobrescribe
fw.write("Hola mundo");
fw.close();
// Para añadir al final en vez de sobrescribir: new FileWriter("pruebas2.txt", true)

2.4. Acceso aleatorio: RandomAccessFile

Permite leer y escribir en cualquier posición del fichero.

Modos de acceso (segundo parámetro del constructor):

  • "r": solo lectura. Escribir lanza IOException.
  • "rw": lectura y escritura.
  • "rwd": lectura y escritura síncronas del contenido. Se escribirán todas las actualizaciones del contenido del fichero.
  • "rws": como rwd, y además escribe los metadatos.

El constructor de RandomAcessFile acepta un File o un String con la ruta y como segundo parámetro el modo de acceso. El método seek(long) posiciona el puntero y el método getFilePointer() devuelve su posición en bytes, como long.

RandomAccessFile raf = new RandomAccessFile("datos.dat", "r");
raf.seek(5);                                  // puntero en el byte 5
System.out.println(raf.getFilePointer());     // 5
int b = raf.read();                           // lee el byte 5 y avanza el puntero
System.out.println((char) b);
System.out.println(raf.getFilePointer());     // 6
raf.close();

3. Operaciones con buffer

Las clases BufferedInputStream, BufferedOutputStream, BufferedReader y BufferedWriter permiten leer y escribir con mejor rendimiento que FileInputStream o FileOutputStream, porque usan un buffer: un espacio temporal en memoria donde se almacenan bloques completos de bytes en lugar de acceder al disco byte a byte. Cada vez que se agota la información del buffer, se carga el siguiente bloque. Como el acceso a memoria es mucho más rápido que el acceso a disco, se reducen los accesos al disco y el rendimiento mejora notablemente.

Utiliza las clases base de esta forma:

BufferedInputStream bis = new BufferedInputStream(new FileInputStream("datos.bin")
